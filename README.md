# AI-Powered Pseudocode to Code Generator

## Overview

AI-Powered Pseudocode to Code Generator is a Full Stack web application that converts pseudocode into executable source code using Large Language Models (LLMs).

## Features

- AI Code Generation
- Java, Python, C, C++
- Brute Force, Better, Optimal Solutions
- Complexity Analysis
- Code Explanation
- Dry Run
- Complexity Analyzer
- Authentication
- Dashboard
- History

## Tech Stack

Frontend

Backend

AI
